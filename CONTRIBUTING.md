# Contributing

## Workflow

Please follow the workflow below:

1. Create a feature branch
2. Make focused changes
3. Commit with clear messages
4. Open a pull request for review

## Branch Naming

## Commit Messages

Prefer clear commit messages, for example:

- bootstrap repository structure
- add initial docker development stack
- add platform architecture documentation

## General Notes

- Keep documentation updated with code changes
- Prefer simple and reproducible setup instructions
- Avoid adding undocumented services or configuration
